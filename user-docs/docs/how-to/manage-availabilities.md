# Gérer ses disponibilités

Indiquer vos disponibilités aide les autres membres à savoir quand vous contacter. Ce guide explique comment les configurer.

## Pourquoi c'est important ?

Les disponibilités permettent de :

- **Faciliter la prise de contact** : Les membres savent quand vous êtes libre
- **Éviter les sollicitations** aux mauvais moments
- **Trouver des partenaires compatibles** avec votre emploi du temps

## Accéder aux disponibilités

1. Allez sur **"Mon profil"**
2. Trouvez la section **"Disponibilités"**
3. Cliquez sur **"Modifier"** ou **"Ajouter"**

## Configurer vos créneaux

### Types de créneaux

| Créneau | Horaires indicatifs |
|---------|---------------------|
| **Matin** | 8h - 12h |
| **Après-midi** | 12h - 18h |
| **Soir** | 18h - 22h |

### Jours de la semaine

Sélectionnez les jours où vous êtes disponible :

- Lundi à Vendredi (jours ouvrés)
- Samedi et Dimanche (week-end)

### Exemple de configuration

**Profil d'un salarié** :

- Soir : Lundi, Mardi, Jeudi
- Après-midi + Soir : Samedi
- Matin : Dimanche

**Profil d'un étudiant** :

- Après-midi : Lundi, Mercredi, Vendredi
- Toute la journée : Week-end

## Ajouter une disponibilité

1. Cliquez sur **"Ajouter une disponibilité"**
2. Sélectionnez le jour
3. Choisissez le créneau (matin/après-midi/soir)
4. Validez

## Supprimer une disponibilité

1. Trouvez la disponibilité à supprimer
2. Cliquez sur l'icône de suppression (🗑️)
3. Confirmez

## Bonnes pratiques

### Soyez réaliste

- N'indiquez que les créneaux où vous êtes **vraiment** disponible
- Mieux vaut peu de créneaux fiables que beaucoup d'incertains

### Mettez à jour régulièrement

- Votre emploi du temps change ? Mettez à jour vos disponibilités
- Avant les vacances, pensez à les ajuster

### Communiquez

- Les disponibilités sont indicatives
- Précisez dans vos messages si vous avez des contraintes particulières

## Affichage sur votre profil

Les autres membres voient vos disponibilités sous forme de badges :

```
📅 Disponible :
- Lundi soir
- Mercredi après-midi
- Samedi matin
```

Cela les aide à vous proposer des créneaux adaptés.

## Pas de disponibilités ?

Si vous n'avez pas configuré vos disponibilités :

- Votre profil affiche "Disponibilités non renseignées"
- Les membres devront vous demander directement par message
